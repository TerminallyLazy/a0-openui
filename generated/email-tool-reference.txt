The following grammar applies only inside the program string argument.
Write one name = expression statement per line. root = EmailTemplate(...) comes first.
Arguments are positional in signature order; arrays contain children; null skips optional middle arguments.
References may precede definitions. Strings are quoted.
EmailTemplate supplies the subject and previewText. This is a draft; export never sends email.
Query, Mutation, @Run and @OpenUrl are unavailable. For UI image search results use ImageCard/ImageCarousel/ImageGrid with actual public HTTPS URLs and source links. Email preview remote images remain blocked.
